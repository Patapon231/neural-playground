# NEURAL PLAYGROUND // Интерактивная лаборатория нейросетей

Полноценное веб-приложение для конструирования, визуализации и реального обучения нейронных сетей прямо в браузере на базе **TensorFlow.js**, выполненное в эстетике научных исследовательских CRT-терминалов 1980–1990-х годов.

## Технологический стек

- **React 18 + TypeScript + Vite**
- **TensorFlow.js (`@tensorflow/tfjs`)** — настоящее создание `tf.Sequential` моделей, расчёт градиентов, обновление весов и прямые проходы в браузере
- **Recharts** — аналитические графики сходимости функции потерь (`Loss`) и точности (`Accuracy` / `R²`)
- **HTML5 Canvas API** — интерактивная визуализация графа нейронов, весов связей, активаций, распространения сигнала и 2D-пространства решений
- **Lucide React** — технические пиктограммы

## Запуск проекта

```bash
npm install
npm run dev
```

Проверка типов и сборка production-бандла:


## Разделы лаборатории

1. **Главная** — оперативная сводка слоёв, нейронов, параметров, статуса обучения, граф текущей сети и журнал последних операций.
2. **Конструктор нейросети** — добавление и удаление скрытых слоёв, изменение числа нейронов и функций активации (`Tanh`, `ReLU`, `Sigmoid`, `ELU`, `Linear`), типовые пресеты и послойная матрица параметров.
3. **Наборы данных** — 4 встроенных набора (`XOR`, `Классификация точек`, `Линейная зависимость`, `Две группы точек`), настройка объёма выборки и шума, интерактивное зондирование координат кликом по 2D-графику.
4. **Обучение** — настройка количества эпох, скорости обучения (`Learning Rate`), размера пакета (`Batch Size`) и оптимизатора (`Adam`, `SGD`, `RMSprop`) с синхронной визуализацией весов и границы решений в реальном времени.
5. **Аналитика** — графики `Loss` и `Accuracy` на основе реального обучения и журнал всех проведённых экспериментов сессии.

## Команды системного терминала

В нижней консоли доступны интерактивные команды:
- `help` — список всех команд
- `status` — состояние ускорителя TensorFlow.js, число активных тензоров в ОЗУ и метрики обучения
- `info` — полная спецификация текущей модели и выборки
- `train` / `stop` / `reset` — управление обучением и сбросом весов из командной строки
- `dataset <xor|circles|linear|clusters>` — переключение набора данных
- `clear` — очистка журнала терминала
